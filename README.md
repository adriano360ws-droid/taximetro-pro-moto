# Tax-metro-pro-Moto
Aplicativo PWA de taxímetro profissional exclusivo para MOTO. Funcionalidades: GPS offline, cálculo de tarifas por período (dia/noite/fim de semana), PIX configurável, link dinâmico para passageiro, comprovante profissional, histórico de corridas. Ícone e título específicos para moto.
